# Saturday Racebook (website)

The website for my Saturday Racebook: Australian metro race fields, odds movements, results, stewards flags, news, and my picks with profit, CLV and calibration tracking.

This repository holds only the page's code. The data lives in a private repository. The page reads it through the GitHub API, using a key that is stored only on the device it was entered on.

Live at: https://sutekke.github.io/racebook/
